MHTSdigiX Deployment Guide

Complete Instructions for Hostinger with maanagaram.com

Document Version: 1.0 | Last Updated: February 2026

IMPORTANT: Hosting Type Required

Your MHTSdigiX website is a full-stack Node.js application with:
  • React frontend
  • Express.js backend
  • PostgreSQL database
  • OpenAI API integration (Meena chatbot)
You need Hostinger VPS Hosting (not shared hosting) because shared hosting doesn't support Node.js backends.

Step 1: Purchase Hostinger VPS Hosting

  1. Go to hostinger.com/vps-hosting
  2. Choose a plan (recommended: KVM 2 or higher)
    • Minimum: 2 GB RAM, 2 CPU cores
    • Recommended: 4 GB RAM, 2 CPU cores
  3. Select Ubuntu 22.04 as Operating System
  4. Complete purchase

Step 2: Connect Your Domain (maanagaram.com)

If domain is registered on Hostinger:

  1. Log in to Hostinger hPanel
  2. Go to Domains → maanagaram.com
  3. Click DNS / Nameservers
  4. Add A Record:
    • Type: A
    • Name: @
    • Points to: [Your VPS IP Address]
    • TTL: 14400
  5. Add another A Record for www:
    • Type: A
    • Name: www
    • Points to: [Your VPS IP Address]

Step 3: Access Your VPS

  1. In Hostinger hPanel, go to VPS section
  2. Note your VPS details: IP Address and Root password
  3. Connect via SSH (use Terminal or PuTTY):
ssh root@YOUR_VPS_IP

Enter root password when prompted.

Step 4: Setup VPS Server Environment

4.1 Update System

apt update && apt upgrade -y

4.2 Install Node.js 20

curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
apt install -y nodejs

4.3 Verify Installation

node --version   # Should show v20.x.x
npm --version    # Should show 10.x.x

4.4 Install PM2 (Process Manager)

npm install -g pm2

4.5 Install Nginx (Web Server)

apt install nginx -y
systemctl start nginx
systemctl enable nginx

4.6 Install PostgreSQL

apt install postgresql postgresql-contrib -y
systemctl start postgresql
systemctl enable postgresql

Step 5: Setup PostgreSQL Database

5.1 Create Database and User

sudo -u postgres psql

In PostgreSQL prompt, run:

CREATE DATABASE mhtsdigix;
CREATE USER mhtsuser WITH ENCRYPTED PASSWORD 'YOUR_SECURE_PASSWORD';
GRANT ALL PRIVILEGES ON DATABASE mhtsdigix TO mhtsuser;
\c mhtsdigix
GRANT ALL ON SCHEMA public TO mhtsuser;
\q

5.2 Note Your Database URL

DATABASE_URL=postgresql://mhtsuser:YOUR_SECURE_PASSWORD@localhost:5432/mhtsdigix

Step 6: Build Your Application (On Replit)

Before deploying, build your application on Replit:

npm run build

Files to Download after build:

  • dist/ folder (built application)
  • package.json
  • package-lock.json
  • drizzle.config.ts
  • shared/ folder
  • server/ folder

Step 7: Upload Files to VPS

7.1 Create Application Directory

mkdir -p /var/www/mhtsdigix
cd /var/www/mhtsdigix

7.2 Upload Files

Use SFTP client (FileZilla, WinSCP) to upload all files to /var/www/mhtsdigix/

7.3 Install Dependencies on VPS

cd /var/www/mhtsdigix
npm install --production

Step 8: Configure Environment Variables

8.1 Create Environment File

nano /var/www/mhtsdigix/.env

8.2 Add These Variables

# Database
DATABASE_URL=postgresql://mhtsuser:YOUR_SECURE_PASSWORD@localhost:5432/mhtsdigix

# Session
SESSION_SECRET=your-super-secret-session-key-minimum-32-characters

# OpenAI API (for Meena chatbot)
OPENAI_API_KEY=sk-your-openai-api-key-here

# Server
NODE_ENV=production
PORT=5000

8.3 Get OpenAI API Key

  1. Go to platform.openai.com
  2. Sign up or log in
  3. Go to API Keys section
  4. Click Create new secret key
  5. Copy the key and paste in .env file

Step 9: Run Database Migrations

cd /var/www/mhtsdigix
npm run db:push

Step 10: Start Application with PM2

10.1 Start the Application

cd /var/www/mhtsdigix
pm2 start dist/index.js --name mhtsdigix

10.2 Save PM2 Configuration

pm2 save
pm2 startup

10.3 Verify Application Running

pm2 status
pm2 logs mhtsdigix

Step 11: Configure Nginx Reverse Proxy

11.1 Create Nginx Configuration

nano /etc/nginx/sites-available/maanagaram.com

11.2 Add This Configuration

server {
    listen 80;
    server_name maanagaram.com www.maanagaram.com;

    location / {
        proxy_pass http://localhost:5000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}

11.3 Enable the Site

ln -s /etc/nginx/sites-available/maanagaram.com /etc/nginx/sites-enabled/
nginx -t
systemctl restart nginx

Step 12: Install SSL Certificate (HTTPS)

12.1 Install Certbot

apt install certbot python3-certbot-nginx -y

12.2 Get SSL Certificate

certbot --nginx -d maanagaram.com -d www.maanagaram.com

Follow prompts: Enter email, agree to terms, choose redirect option (Yes).

12.3 Auto-Renewal Test

certbot renew --dry-run

Step 13: Configure Firewall

ufw allow OpenSSH
ufw allow 'Nginx Full'
ufw enable
ufw status

Step 14: Verify Deployment

Open browser and visit:

  • https://maanagaram.com
  • https://www.maanagaram.com

Test Checklist:

  • Homepage loads correctly
  • All pages navigate properly
  • Contact form works
  • Meena chatbot responds
  • All service pages display
  • FAQ section works
  • Careers page shows jobs

Troubleshooting Commands

Issue Command
Check app status pm2 status
View app logs pm2 logs mhtsdigix --lines 100
Check Nginx status systemctl status nginx
View Nginx errors tail -f /var/log/nginx/error.log
Check PostgreSQL systemctl status postgresql
Restart app pm2 restart mhtsdigix
Restart Nginx systemctl restart nginx
